# 🚀 Ujjwal Kumar — 3D Interactive Developer Portfolio

A modern, high-performance personal portfolio built with **Next.js 16 (Turbopack)**, **React 19**, **Tailwind CSS**, and **Framer Motion**, featuring an interactive 3D scene, animated Bento About modal, dynamic project showcases, and verified internship credentials.

## ✨ Key Features

- 🌌 **Interactive 3D Scene** — Interactive Spline 3D elements and animated cosmic particle system.
- 🪟 **Animated Bento About Modal** — Smooth spring-animated profile card showcasing bio, tech stack, personality, and developer journey.
- 💼 **Full-Stack & Web3 Projects** — Detailed modal showcases with architecture diagrams, REST API endpoints, live links, and GitHub repositories.
- 📜 **Verified Internship Certificates** — Interactive credentials for virtual internships supported by Google for Developers, Altair, and Alteryx SparkED.
- 📬 **Live Contact Form** — Serverless email dispatch pipeline delivering visitor messages straight to Gmail via [Resend](https://resend.com).
- 🌓 **Dynamic Theme Switching** — Dark and Light mode with smooth CSS variables and custom micro-interactions.
- 📱 **100% Mobile Optimized** — Responsive layouts, adaptive typography, and touch-friendly drawers on all screen sizes.

## 🚀 Getting Started Locally

### Prerequisites
- **Node.js**: v18.18 or later
- **Package Manager**: `npm`, `pnpm`, or `yarn`

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ujjwalk2523/3d-portfolio.git
   cd 3d-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   Create a `.env.local` file in the root directory:
   ```env
   RESEND_API_KEY=your_resend_api_key_here
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. Open **[http://localhost:3000](http://localhost:3000)** in your browser.
